# Assets

Everything the game loads lives under `assets/` and ships as `app/assets/`
in releases. No asset is downloaded at runtime.

| Directory | Contents | Origin | License |
|---|---|---|---|
| `models/` | 25 low-poly GLB models: astronaut, husk, brute, skitter, bloater, drop pod, weapons, drone, ore decorations, pickups, beacon, ship stations and modules, ship exterior, planet | Generated by `DevUtils/assets/generate_models.py` | Original to this project |
| `sounds/` | 32 effects and 4 loops (ship hum, planet wind, ship and surface music) | Generated by `DevUtils/assets/generate_sounds.py` | Original to this project |
| `kenney/blaster-kit/` | `blaster-d.glb`, `blaster-f.glb`, `crate-medium.glb`, `crate-wide.glb` + colormap | [Kenney Blaster Kit](https://kenney.nl/assets/blaster-kit), via Quasar's Nightwatch example | CC0 1.0 (`License.txt`) |

| `fonts/` | `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` | DejaVu fonts, via Quasar's Starfall example | Bitstream Vera license; DejaVu changes public domain (`LICENSE-DejaVu.txt`) |

## Generated models

`generate_models.py` builds models from convex solids (boxes, prisms, cones,
bipyramid crystals, icospheres) with flat normals and glTF base-color,
metallic/roughness and emissive factors, the subset Quasar's classic material
conversion supports. Output is byte-for-byte deterministic.

Each animated part is its own named node whose translation is the joint pivot:

| Model | Animated nodes |
|---|---|
| astronaut, husk, brute | `torso`, `head`, `arm_l`, `arm_r`, `leg_l`, `leg_r` |
| skitter | `body`, `head`, `leg_l0..2`, `leg_r0..2` |
| bloater | `body`, `leg_l`, `leg_r` |
| drop-pod | `body`, `door`, `thruster` |
| drone | `core`, `rotor` |
| nav-console / reactor-core / drill-rig / beacon | `holo` / `core` / `bit` / `light` |

Characters face +Z with feet at y = 0. Ore decorations span the [-1, 1] cube
used for wall blocks, so they are drawn with the block's own transform.

## Generated sounds

`generate_sounds.py` synthesizes 44.1 kHz mono 16-bit WAVs from oscillators,
filtered noise and envelopes with a fixed seed. Loops are whole oscillator
cycles or crossfaded into themselves so `LoopMode::Whole` repeats without
clicks.

## Regenerating

```sh
python3 DevUtils/assets/generate_models.py
python3 DevUtils/assets/generate_sounds.py
cargo run --release -- --cover assets/basalt/cover.png
cargo test   # all_models_decode, rigs_expose_their_joints, all_clips_decode
```
